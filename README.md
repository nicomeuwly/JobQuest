# JobQuest

JobQuest is a personal job-search manager built to keep track of job applications in one place — the companies contacted, the status of each application, and the next steps to take. The project is being developed as a way to deepen my hands-on experience with Angular and modern frontend best practices.

> **Status:** Work in progress 🚧 — actively developed as a learning project. Some features are still being built.

## Why this project

Job hunting quickly becomes hard to track across spreadsheets, emails and bookmarks. JobQuest is my attempt to solve that with a clean, focused interface, while at the same time strengthening my skills in:

- Angular's component-based architecture
- TypeScript and strong typing
- Reactive state management and routing
- Clean, maintainable and accessible UI

## Features

- Track job applications and their current status
- Organize applications by company and role
- Clear, responsive interface focused on usability

*(More features are planned as the project evolves — see the roadmap below.)*

## Getting started

### Prerequisites

- [Node.js](https://nodejs.org/) (LTS recommended)
- [Angular CLI](https://angular.dev/tools/cli)

### Installation

```bash
git clone https://github.com/nicomeuwly/JobQuest.git
cd JobQuest
npm install
```

### Development server

```bash
ng serve
```

Then open your browser at `http://localhost:4200/`. The app reloads automatically when you change a source file.

### Build

```bash
ng build
```

Build artifacts are stored in the `dist/` directory.

### Running unit tests

```bash
ng test
```
